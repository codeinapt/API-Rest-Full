- **Filters and sorting.** The decisions from this session are applied:
  - `Status` defaults to Active, and `All` applies no filter.
  - `lowStock == true` filters `Stock <= MinimumStock`. Null or false applies no filter.
  - `search` is Name contains OR Sku contains. Whitespace-only means no filter.
  - `sortBy` is an allow-list enum (name, sku, stock), validated with `IsInEnum`.
  - `sortDirection` defaults to asc, with `ThenBy(Id)` as the tie-breaker.
- **EF conventions (`docs/ai/08`).** The query reads from the read context, projects to the DTO and counts before paging. It computes `IsLowStock` in the projection.
