## SPEC mapping
- **RP-01:** SKU length 3–50 and pattern `^[A-Z0-9-]+\z` → `VALIDATION_ERROR`. The `"MILK-1L\n"` case covers the trailing newline.
- **RP-02 and RP-05:** name 3–150 and not blank, description at most 1000, `MinimumStock` ≥ 0 → `VALIDATION_ERROR`.
- **RP-03 and RP-07:** `Create` and `ChangeCategory` raise `REFERENCED_CATEGORY_INVALID {category.Id}` for an inactive category.
- **RP-04 and RP-06:** a new product has `Stock = 0`; no member edits `Stock`; `UpdateDetails` changes only name, description, minimum stock and `UpdatedAt`.
- **RP-08:** `Delete` requires `Stock = 0` (`PRODUCT_HAS_STOCK {stock}`) and records `Discontinued` with null notes.
- **RP-09:** the reason must be defined, notes are required when the reason is `Other` and are at most 500 characters; `DeactivatedAt` and `DeactivatedBy` are recorded.
- **RP-10:** `UpdateDetails`, `ChangeCategory`, `Delete` and `Deactivate` raise `PRODUCT_INACTIVE {id}` on an inactive product.
- **RP-11:** `Reactivate` raises `PRODUCT_ALREADY_ACTIVE {id}` on an active product.
- **RP-12:** `Reactivate` raises `CATEGORY_INACTIVE {category.Id}`. SKU availability is left to the handler (T-17).
- **RP-13:** `Reactivate` keeps the stock and the previous deactivation data, and sets `ReactivatedAt` and `ReactivatedBy`.
- **RP-14:** `IsLowStock()` returns `Stock <= MinimumStock`.
- **State machine §5.1:** all transitions match.
- **Enum:** `DeactivationReason` values 1–5 match `DOMAIN_LOGIC.md` §2.
