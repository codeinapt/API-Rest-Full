# Informes de auditoría de gobernanza

Un archivo `T-XX.md` por tarea, generado por el subagente `governance-auditor` (`.claude/agents/governance-auditor.md`) sobre el diff de la tarea.

- Un informe **FAIL** no se borra: se corrige el código, se vuelve a auditar y se añade el nuevo resultado al mismo archivo. El historial de correcciones es evidencia de la revisión.
- El humano revisa cada informe antes de marcar la tarea como completada.
